GHOSTRUDEL

Quick start

A local Strudel workspace for writing, playing and switching live-coded tracks. Pick a track, edit the code, then re-evaluate it while it runs.

  • ⌘/Ctrl K — open the track picker, search a sketch, then press Enter to load it
  • Ctrl Enter — play / re-evaluate the current code · Ctrl . — stop
  • Make a new track: copy a sample from tracks/, edit the parts, then reload or switch to it from the picker
  • Live edit: change notes or patterns in the editor, then press Ctrl Enter to hot-swap without restarting the clock
  • Visuals: keep ._pianoroll() for melodic parts, ._punchcard() for drums, and a final .pianoroll(...) / .punchcard(...) for the full background
  • Themes: click the swatches top-right, or press Ctrl H / Ctrl L

Browser edits are temporary — copy good bits back into the matching .strudel.js file to keep them.
